# 白盒复刻边界

我们持有像素蛋糕（PixCake）的完整逆向证据（Ghidra 反编译、SQL schema、字符串挖掘，存档于 `~/Desktop/rea/`），其加密资产（1.44GB pixcook blob、103 份加密 effect.json）的解密在技术上并非不可为。我们决定采用**纯白盒复刻**：逆向所得仅作架构与数据模型层面的设计参考，不解密任何受保护载荷，不提取、不搬运任何第三方资产（模型权重、LUT、素材、代码），全部实现基于开源组件与自研代码。

## Considered Options

- **解密后 1:1 复刻**：拒绝。绕过 DRM + 资产搬运使项目在法律上不可成立；代码库一旦被污染资产进入即无法洗净，堵死任何后续分发可能。
- **完全不看逆向结果的净室复刻**：拒绝。白白放弃已合法获得的架构理解（记录链、当前态指针、按人寻址、预设方案三元组），且净室并不能换来额外法律保护。

## Consequences

- 质量上限低于商业原版（缺少其多年调校的模型与色彩资产）——这是 demo+自用定位下明知故犯的取舍，不是疏漏。
- `~/Desktop/rea/`（证据）与 `~/Desktop/pixretouch/`（实现）保持物理分离；实现侧只允许存在"设计动机"层面的文字引用，不允许拷贝任何逆向产物或提取资产。
