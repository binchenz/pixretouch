# 记录链数据模型：当前态指针 + 急切渲染缓存

复刻像素蛋糕的非破坏编辑核心：每张图持有一条追加式**记录链**（每条记录 = 能力 + 参数 + 前驱指针），**当前态指针**指向生效记录，回滚 = 移动指针而非删除记录。与原版的惰性渲染（预览/全分辨率分离）不同，我们在记录追加时**立即渲染**，产物按（输入哈希, 能力, 参数）内容寻址入缓存；原图永远只读。

## Considered Options

- **惰性渲染引擎**（原版做法）：拒绝。它服务于实时滑杆 GUI 与百兆 RAW，我们没有这类交互面，复杂度换不来收益。
- **破坏性编辑 + undo 栈**：拒绝。会失去"按调用标识回滚"的 agent 能力与操作可审计性——而这正是复刻此模型的全部理由（原版敢开放 MCP 也是靠它）。

## Consequences

- 每次生效编辑占用一份输出 JPEG 的磁盘（缓存命中则零成本）；当前磁盘余量 56GB，自用规模足够，需在 README 标注缓存清理策略。
- 工具层接近纯函数：追加记录 → 查缓存/渲染 → 返回输出哈希；引擎无渲染时机状态，崩溃恢复只需重放指针。
